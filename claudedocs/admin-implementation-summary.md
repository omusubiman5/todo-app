## セキュリティ特徴

### 認証・認可
- **二重認証**: Bearer Token + Admin Session Token
- **ロールベースアクセス制御**: 4階層の管理者ロール
- **細粒度権限**: 12種類の詳細権限
- **セッション管理**: 30分タイムアウト、アクティビティ追跡

### セキュリティ制約
- **自己操作防止**: 管理者は自分自身を操作不可
- **権限エスカレーション防止**: super_admin以外は他のsuper_adminを操作不可
- **監査証跡**: 全操作の完全な記録
- **データサニタイゼーション**: 機密情報の自動除去

### データ保護
- **パスワード履歴**: ハッシュ化された履歴管理
- **IPアドレス追跡**: 不正アクセス検出
- **セッション検証**: 定期的な有効性確認
